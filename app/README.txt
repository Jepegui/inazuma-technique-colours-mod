TECHNIQUE COLOURS 1.3 - recoloured special moves for Inazuma Fantasy

  1. Unzip everything first (the app does not work from inside a zip),
     NOT inside the game's mods folder (the app is not a mod), nor inside
     Program Files (see below).
  2. Open "Technique Colours.bat" (Microsoft Edge) or technique-colours.html
     in Edge or Chrome.
  3. Choose the game's mods folder (the game you start with the mod launcher,
     with VRFW and InazumaFantasy in it).
  4. Search the original move, choose its colour, name, price and TP / power,
     and click "Create move". To preview the colours on the move's video,
     download it from https://zukan.inazuma.jp/en/skill/ and load it in the app.
  5. With the game closed, click "Generate the mod", then switch on
     "Technique Colours" in the launcher. Your moves are in Inazuma Fantasy's
     Technique Shop.

  - The app only writes inside mods\TechniqueColours (and the mods you make
    with "+ New"). Nothing leaves your computer.
  - Before you delete a move in the app, take it off the players who learned it.
  - Do not use online play or cross-save with mods.
  - Program Files: Edge and Chrome cannot open folders inside Program Files,
    Program Files (x86), Windows or AppData. Keep the app AND the game outside
    them. If the game is in Steam's default library, move it in Steam:
    right-click the game > Properties > Installed Files > Move install folder.

The name banners use the Rum Raisin font by default, or one of six others, or a font file of your own.
